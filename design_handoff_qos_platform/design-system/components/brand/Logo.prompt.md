# Logo

The approved QOS wordmark, rendered from the supplied raster artwork.

```jsx
<Logo variant="navy" height={22} assetBase="../../assets/" />
```

Variants: `light` (navy letterforms on Cloud/white), `navy` (supplied dark-background cut, for the dark shell and login), `icon` (supplied app icon). Never below 24px wide-mark height; never recolour or redraw.
