# SideNav

The QOS left navigation, with expandable groups.

```jsx
<SideNav brand={<Logo variant="navy" height={20} />} groups={NAV} activeId="orders" onNavigate={go} />
```

Wrap in `[data-qos-theme="dark"]` for the branded deep-navy shell. Nav order is fixed platform-wide: Home, Orders, Catalogue, Customers, Sales Channels, Locations, Integrations, Analytics, Team, Settings.
